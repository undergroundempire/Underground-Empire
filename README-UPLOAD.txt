UNDERGROUND EMPIRE — upload guide

FILES:
- index.html
- style.css
- script.js
- Bohee.jpg (your own photo)

IMPORTANT:
1. Keep all four files in the SAME folder at the root of your GitHub repository.
2. The photo filename must be exactly: Bohee.jpg (capital B, lowercase ohee, .jpg).
3. Open GitHub repository -> Add file -> Upload files, select these files, then Commit changes.
4. In Settings -> Pages, publish from the main branch and /(root) folder.
5. Open the exact live URL shown in Settings -> Pages. For this repository it should usually be:
   https://undergroundempire.github.io/Underground-Empire/
6. This is a static website. It does not include a secure admin login or server-side content editor.
