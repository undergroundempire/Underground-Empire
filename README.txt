UNDERGROUND EMPIRE WEBSITE — RESPONSIVE STARTER

FILES
- index.html: website sections and content
- style.css: responsive mobile/tablet/desktop design, red glow and animated crown
- script.js: mobile menu, searchable media previews and local preview uploader

HOW TO UPLOAD TO GITHUB (PHONE OR COMPUTER)
1. Download and extract this ZIP.
2. Open your repository: https://github.com/undergroundempire/Underground-Empire
3. Upload index.html, style.css, script.js, and README.txt to the repository root.
4. If GitHub asks, replace the old files, then commit changes.
5. Open GitHub Pages site and refresh. If it shows old content, wait a few minutes and refresh.

IMPORTANT LIMITATION
GitHub Pages is static hosting. The included uploader is only a browser preview:
- it does not transfer files to GitHub or a server;
- files are not stored permanently and are not automatically public;
- preview files disappear when the page is refreshed/closed;
- there is no secure admin login in this starter.

To support real public uploads from phone/computer, secure admin access, persistent cloud storage, and automatic posting to Facebook/Instagram/YouTube, the site needs a backend/storage service plus each platform's API/OAuth permissions. Do not put secret API keys or passwords in script.js or any public GitHub file.

PERSONALIZE
1. Replace the hero background in style.css: find ".hero:after" and change its background styling or add your own image.
2. Replace social URLs in script.js and the social links in index.html with your official profile URLs.
3. You can change text and colors in index.html and style.css.

MOBILE + DESKTOP
The layout uses responsive CSS breakpoints. It automatically adjusts for phone, tablet, and desktop screen sizes. No separate mobile version is needed.
