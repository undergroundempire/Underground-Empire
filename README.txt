UNDERGROUND EMPIRE WEBSITE STARTER
==================================

FILES
- index.html: public homepage
- style.css: responsive black/red/gold styling
- script.js: mobile menu and search
- admin.html: demo-only admin panel UI
- assets/mockup-reference.png: generated design reference (if available)

FONT
Uses Google Fonts: Permanent Marker, Bebas Neue, Roboto. Internet is needed for the exact web fonts.
The mockup image is one flattened image, so its background artwork cannot be extracted as separate original banners/icons. This package recreates the layout using CSS and text/icons.

IMPORTANT ABOUT ADMIN UPLOADS
GitHub Pages is static hosting. The included admin page is only a visual/demo panel; it is NOT secure login and selected files are NOT uploaded or made public.
For real secure admin login and public audio/video/photo uploads, connect a backend and storage service (for example Supabase/Firebase or a custom server), then update the upload code. Never store an admin password in HTML/JavaScript.

ANDROID GITHUB PAGES SETUP
1. Download and extract the ZIP.
2. In your GitHub repository, upload index.html, style.css, script.js, admin.html and the assets folder contents.
3. Keep the filenames and folder names exactly the same.
4. In repository Settings > Pages, select the branch and folder that contain index.html.
5. Wait for GitHub Pages to publish, then open your website.
